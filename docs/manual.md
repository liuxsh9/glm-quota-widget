# 使用细节

[README](../README.md) 只讲「装好怎么用起来」；这份讲深一点的用法：多账户、贴边模式、设置、快捷操作、峰谷时段，以及已知边界。

## 多账户

每家可以添加任意多个账户（设置页「＋ 添加账户」），各有独立凭据、独立状态、独立消费历史。胶囊有两种布局（**设置 › 通用 › 胶囊布局**）：

- **切换**（默认）：胶囊只显示「当前账户」，数据右侧有一枚账户标签——点它弹出账户菜单，或者在胶囊上**滚轮**循环切。标签上写着当前账户名，瞟一眼就知道在看谁
- **平铺**：每个账户各占一格，格顶写账户名，一眼看全——适合「就想同时盯着几个号」。点账户名把它设为当前账户

切账户的三种方式：面板里点账户 chips、胶囊上点标签（或滚轮）、平铺模式下点账户名。

颜色按**每个账户自己的水位**算：平铺时可能左边还是青的、右边已经红了。托盘图标取全局最差档位，任何一个账户凭据失效都会变红，不会被别的好状态掩盖。

**停用**（设置页账户行右侧那个按钮）＝「别再拉、也别再显示」。某家一个启用账户都不剩时，它的胶囊列、面板页签、托盘那一行**一起收掉**——不会留一列显示着停用前的旧读数；账户本身仍留在设置页，凭据不动，随时能再启用。重新启用会立刻拉一次，不用等下一个刷新周期。

## 贴边模式

把挂件拖到屏幕**左 / 右边缘**松手，它就收成一列竖排的圆圈——每个**启用**账户一个：环色 = 该账户的百分比（连续渐变）、中心 = 厂商 logo、环下 = 数字。

**吸附收口**（流体融合）：贴边侧整条并入屏幕物理边缘（不描边、没有缝）；外露的上下两端用反向圆角（喇叭口）以竖直切线切进屏幕边。四个角是**同一个**连续曲率圆角（r=15、平滑度 0.6，同 iOS / Figma 的 squircle 角：直边 → 曲率从 0 渐起的三次曲线 → 圆弧 → 三次曲线 → 直边），凸的在远端、凹的在贴边侧，曲率完全匹配；描边在喇叭口里渐隐、化进屏幕边。松手吸附的瞬间播一段 460ms 的收口动画（反向圆角从 0 长到满，像液体沿屏幕边爬出弯月面）。上下留白 36px = 喇叭口高 24 + 圆圈间距 12。

**吸附规则**：

- 松手时距**所在屏幕的左 / 右边缘** ≤ 28 DIP 就吸，再远就留在原地
- **两块屏之间的接缝同样可以贴**（跨屏拖动不会被打断——吸附只在松手时判定一次）
- 只贴左右，不贴上下
- 贴的是**工作区**的边：任务栏在侧边时，圆圈贴在任务栏旁边

**圆圈显示什么**：每个圆圈的百分比口径单独配（设置页「贴边圆圈」段）。

| 这家 | 可选口径 |
|---|---|
| GLM | 5 小时 / 周 / **5 小时 + 周（双环）**：外环 5 小时、内环（细一档）周，数字跟外环 |
| 火山方舟 | 5 小时 / 周 / 月 |
| Codex | 周（默认）/ 5 小时 / 月 / 5 小时 + 周（双环） |
| DeepSeek | 今日 / 近 7 天 / 本月，另填一个预算金额当作 100%；圆圈下可选显示**百分比**或**金额**（如 ¥3.21） |

DeepSeek 没填预算 → 圆圈只画底环、数字显示「–」（选了「金额」则照常显示消费额）。超预算时数字照实显示（如 150%），圆环画满。选「金额」且填了预算：数字是金额，圆环仍按 消费 ÷ 预算 画。

**圆圈大小**：鼠标放在圆圈上 `Ctrl+滚轮` 缩放（0.6–1.6，`Ctrl+0` 复位）；或设置页「贴边圆圈」段的「圆圈大小」下拉（小 / 标准 / 大 / 特大，滚轮调出的非预设值显示成「自定义」）。

**悬停看详情**：鼠标移到圆圈上，该账户的详情卡片从圆圈内侧飞出——内容就是面板里这个账户的那一页；点卡片空白 = 打开完整面板到这个账户。

**挪了屏也不丢**：拔插屏 / 换分辨率后，圆圈自动贴到离它最近的那块屏的同侧边；「找回窗口」清掉贴边记忆，挂件回到胶囊（主屏右上角）。

## 设置

设置页按「这个设置影响谁」分段，内容可滚动：

| 段 | 放什么 |
|---|---|
| **GLM Coding Plan** | 账户列表（添加 / 编辑 / 停用 / 删除，带状态点与凭据尾号）；配额提醒（阈值、重置提醒、超预期变色）；官网入口 |
| **DeepSeek 官方 API** | 账户列表（每账户含 API Key + 选配平台令牌）；余额高频采样；用量页入口 |
| **火山方舟 Coding / Agent Plan** | 账户列表（每账户含 AK/SK + **套餐**下拉）；控制台入口 |
| **OpenAI Codex** | 账户列表（每账户含凭据来源 + auth.json）；ChatGPT 用量页入口 |
| **通用** | 刷新频率、界面主题、**胶囊布局**、开机自启、窗口置顶（胶囊布局只在配了多账户时出现） |

配额提醒（阈值 / 重置提醒 / 超预期变色）是**全局一份**，挂在 GLM 那一段下面，对 GLM、火山方舟与 Codex 同时生效。

**保存行为**：开关与下拉**改完立即生效**（右上角闪一下「✓ 已保存」）；凭据在「添加 / 编辑」表单里显式保存。凭据粘贴格式不对时会明确报错并保留旧值，不会静默丢弃。

## 快捷操作

**胶囊**：单击 = 展开面板；右键 = 菜单；拖动 = 换位置。

**贴边列**：拖动 = 换位置（拖离边缘松手即回胶囊）；悬停圆圈 = 看详情卡片；点圆圈 = 打开该账户面板；`Ctrl+滚轮` = 缩放圆圈大小；右键 = 菜单（含「取消贴边」）。

**展开态面板**：拖动任意处 = 移动；点空白处 = 收起；`Ctrl+滚轮` = 等比缩放（80%–160%，`Ctrl+0` 复位）；`Esc` = 收起。

**托盘**：左键 = 展开 / 收起；菜单 →「打开日志文件夹」「找回窗口」（胶囊被拔插屏 / 睡眠唤醒搞丢时，把它拉回主屏，不用重启）。

## 峰谷时段（两家规则不同，均以北京时间 UTC+8 为准）

| | 高峰时段 | 空闲时段的优惠 |
|---|---|---|
| **DeepSeek** | 周一至周五 09:00–12:00、14:00–18:00 | 空闲时段价格是高峰的**一半**，周末全天按低谷价 |
| **GLM Coding Plan** | 周一至周五 14:00–18:00 | 按**更低的积分系数**抵扣，倍率随模型而变（如 GLM-5.3 非高峰 1 倍 / 高峰 3 倍）。所以界面上只报时段、不写死折扣 |

其余时间都是空闲时段。注意 **GLM 的高峰是 DeepSeek 的子集**：工作日上午 9–12 点只有 DeepSeek 贵。

火山方舟的套餐**按调用次数计费，不分峰谷**；Codex 按消息量折算、同样不分峰谷——两家面板上那一格恒为「—」。

## 已知边界

- GLM 的 Cookie JWT 约 3 天失效（API Key 长期有效），挂件靠接口返回判定并提醒
- DeepSeek 余额是**账号级**的：同账号下所有 Key、所有客户端的消耗都算进同一份余额
- DeepSeek 平台账单是**私有接口**（非公开契约），字段可能随官网改版变化；解析失败只降级这一路。它按 UTC 日界切天，「今日」在北京时间 08:00 前后会有一次跳变
- 未配平台令牌时的消费推算依赖挂件运行，历史样本保留 90 天（`ds-history.json`）
- 火山方舟的**Coding Plan 只返回百分比**，看不到「已用 / 总量」（面板那一行留空）；Agent Plan 才有绝对值
- 火山套餐额度按**调用次数**计，不是 token；也不分峰谷
- 火山的「5 小时」窗口按**固定档期**假设（窗口开始 = 重置时间 − 5 小时）。若官方实际是随用随滑的窗口，进度条的「预期」会偏乐观
- 火山凭据是**账号级 AK/SK**（务必用只读子账号，见 README 的「上手」），权限比一个 API Key 大得多；挂件只是照常明文存在本机 config.json 里
- Codex 的 access_token 约 **10 天**过期（刻意不替用户续期，见[数据来源](internals.md)）；「读本机」来源不受影响
- 多显示器以主显示器工作区为定位基准：拔屏 / 插屏 / 度量变化三个事件统一走 300ms 防抖，落定后把窗口收回工作区；睡眠唤醒锁屏解锁后还会再自检两次。面板宽 326 固定，高度按实测内容决定——GLM 与 DeepSeek 等高（两页切来切去窗口一像素不动），火山 / Codex 那页多一个「月」块、进 / 出时窗口会跟着变高变矮
- 万一窗口还是没出现（例如解锁后它落在一块黑着的屏上），托盘菜单 →「找回窗口」重置位置并强制拉回主屏右上角
- 贴边详情的飞出卡片是独立的透明窗口（不抢焦点）：它的真实焦点行为与多屏 DPI 表现未经真机实测，以 Windows 实测为准；悬停期间拔插屏，卡片会停在旧位置，直到下一次悬停时复位
- 「近 1 小时」「5 分钟柱」的分辨率 = 余额刷新频率（默认 2 分钟）；关掉高频采样时最细那档基本画不出东西
