怎么获取？（不配也能用：只配 API Key 即可看余额）
  1. 登录 platform.deepseek.com → F12 → 「应用 / Application」→ Local Storage → platform.deepseek.com
  2. 找到 userToken 键 → 复制整段值（形如 {"value":"…"}，自动提取其中的 token）
  3. 粘贴到上方 → 保存，即可看到精确的每日消费、本月账单与逐模型 token
  4. 该令牌是平台登录态，会过期（比 GLM 的 Cookie 还不稳定），过期后挂件会提示，重复上述步骤即可
  5. 不配置时，消费数字由本机余额差值推算：挂件没运行的时段补不回来，头几天数字会偏少

通用

本段的开关与下拉都是改完立即生效并保存；只有上面的凭据才需要点「保存并刷新」。

GLM 配额与 DeepSeek 平台账单走这个频率。这两个接口有限流/风控，所以不建议更快。

余额是 DeepSeek 实时读数的唯一来源——「最近 5 分钟」「1 小时柱图」的分辨率就等于这个间隔。
关掉则余额跟上面的刷新频率一起走（那时细粒度柱图会变稀）。

自动刷新带 ±20s 随机抖动，另有托盘「立即刷新」；请求直连 open.bigmodel.cn / api.deepseek.com，不会被 CORS 拦截。所有凭据只保存在本机 config.json，不会外发。
