  1. 打开 bigmodel.cn 并登录（下方「打开官网」按钮直达）
  2. 按 F12 打开开发者工具 → 顶部切到「应用 / Application」标签
  3. 左侧「存储 → Cookie」→ 点开 bigmodel.cn 域名
  4. 列表中找 bigmodel_token_production → 双击「值」列全选 → Ctrl+C 复制
  5. 回到这里粘贴到上方输入框 → 点「保存并刷新」即可

默认 10 分钟自动刷新（附随机抖动），另有托盘「立即刷新」；请求直连 open.bigmodel.cn，不会被 CORS 拦截，也远低于限流阈值。Token 只保存在本机。
